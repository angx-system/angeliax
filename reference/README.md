# reference

*UI/UX reference only — not architecture.*

Screenshots and markup from the original Codeberg prototype, now archived. The prototype used a centralized relay and predates the current Hypercore-based specification. Kept here only for the visual language the demos in [demos/](./demos) build on.

- `01–07` — actual prototype screens (running code).
- `08–11` — designed but never built: client type declaration, library, observe, base.
- `model-screens-source.html` — source markup for 08–11.

Full history: [codeberg.org/angx-protocol/angx-prototype](https://codeberg.org/angx-protocol/angx-prototype) (archived).
